[[b1-1]]에서 배운 것. 과제 목표 "Flexbox와 Grid의 차이, 언제 각각을 고르는지".

## 차이
| | Flexbox | Grid |
|---|---|---|
| 방향 | 1차원 (한 줄: 가로 또는 세로) | 2차원 (행과 열 동시에) |
| 크기를 정하는 쪽 | 내용물 크기에서 출발해 남는 공간을 나눔 | 틀(열·행)을 먼저 정하고 내용물을 넣음 |
| 잘 맞는 곳 | 네비게이션, 버튼 묶음, 칩 목록, 카드 안 정렬 | 카드 목록, 대시보드처럼 칸이 맞아야 하는 배치 |

## 이 페이지에서 고른 이유
- 네비(`.nav`), 버튼 묶음, 기술 칩: 한 줄로 늘어놓고 간격만 맞추면 되니 Flex.
- 프로젝트 카드, 성과 수치 카드, 기술 그룹: 화면 폭에 따라 열 개수가 바뀌고 칸 폭이 같아야 하니 Grid.
- `repeat(auto-fit, minmax(280px, 1fr))`: 미디어 쿼리 없이 폭에 맞춰 열 개수가 바뀐다.
  - `auto-fit`은 빈 칸을 없애고 있는 카드를 늘린다 → 카드 1장이면 한 줄을 다 차지한다.
  - `auto-fill`은 빈 칸을 남겨 둔다 → 카드 수와 상관없이 폭이 일정하다. 성과 카드가 하나뿐인 줄이 너무 넓어져서 `auto-fill`로 바꿨다.

## 모바일 퍼스트 (`min-width`)
- 기본 스타일을 작은 화면 기준으로 쓰고, `@media (min-width: 768px)`에서 큰 화면용으로 **덮어쓴다**. `max-width`로 쓰면 반대로 데스크톱이 기본이 된다.
- 문답에서 놓친 부분: 768px 이상에서 실제로 덮어쓰는 규칙까지 말할 수 있어야 한다 ([[b1-1-review-qa]] Q2).
  - `.nav__toggle { display: none }` → 햄버거 숨김
  - `.nav__menu { display: flex; flex-direction: row; order: 0; flex-basis: auto }` → 메뉴를 항상, 가로로, 로고와 테마 버튼 사이에, 한 줄을 다 차지하지 않게
