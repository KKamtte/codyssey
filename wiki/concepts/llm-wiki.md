[[karpathy-llm-wiki]] 패턴을 기본으로 하고, 다음을 바꾸거나 더했다. 실제 규칙 문장은 [[AGENTS]]에만 있고, 여기에는 무엇을 왜 정했는지만 적는다.

| 항목 | 결정 | 이유 |
|---|---|---|
| 규칙 파일 | `AGENTS.md` 본문 + `CLAUDE.md`는 `@AGENTS.md` 한 줄 | Claude Code가 주 도구지만 ChatGPT/Codex도 쓸 수 있게 |
| 링크 | Obsidian `[[링크]]` | 나중에 Obsidian으로 열어 그래프 보기 |
| 위치 | 과제 레포 안 `codyssey/wiki/` (규칙 파일은 레포 루트) | 이 학습용으로만 쓰므로 한 레포로. 클론·연결도 한 번 |
| Git 운영 | PR 없이 운영, 미션만 작업 브랜치 + merge 커밋 | 작업을 Claude에 맡기므로 PR 리뷰 단계가 필요 없음. 미션은 단계별 기록을 남기고, 위키·규칙 작업은 단순하게 |
| 커밋 시점 | 사용자가 요청할 때 커밋, push는 확인 후 | 여러 수정을 모아 의미 단위로 남기려고. 이 PC의 Claude 메모가 아니라 규칙 파일에 둬야 집·모바일에서도 같게 동작 |
| 도구 | Claude Code CLI + 모바일 앱 Claude Code | 집, 외부 어디서든 이어서 |
| 공개 | 공개 레포 | 학칙상 금지 조항 없음 ([[codyssey]]) |
| 인수인계 | 별도 `now.md` 없이 `log.md` 최근 기록 + `wiki/plans/` | 원문 구조 유지 |
| plans/ | 원문에 없는 추가 폴더. 미션별 `<코드>.md` | 과제 README는 제출물이라 계획·미결정 사항을 분리 |
| 규칙 위치 | 규칙은 AGENTS.md 한 곳, 위키는 이유만 | 규칙이 여러 페이지에 복사되어 바뀔 때마다 어긋났음 (2026-10-14) |
| 개념 축적 | 미션 완료 때 배운 개념을 concepts/에 | 계획·기록만 쌓이고 지식이 안 쌓이는 것을 막으려고. 원문의 "누적되는 위키" 취지 |

## 원문과 다른 점

- 원문에는 "어디서든 이어서"라는 요구가 없다. 그래서 GitHub 레포를 기준 저장소로 두고 시작/끝 git 규칙을 추가했다.
- frontmatter 필드(`title`, `updated`, `sources`)는 Lint에서 낡은 페이지와 근거 없는 내용을 찾으려고 정했다.
