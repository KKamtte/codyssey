## 결정 사항

| # | 항목 | 상태 |
|---|---|---|
| 0 | 배포 방식 | **결정**: codyssey 레포 전체를 Pages로 (`main` / 루트, `.nojekyll`). 이후 미션도 같은 방식으로 각자 경로에 배포 |
| 1 | 공개할 내 정보 | **결정 (10/15)**: 이름 김승현, 소개는 이력서 [소개] 기반, 이메일 공개, GitHub 링크. 전화번호·학력 증명 등은 넣지 않음. 이유: 공개 레포라 연락에 필요한 최소한만 |
| 2 | 프로필 사진 | **결정 (10/15)**: 증명사진을 참고한 캐릭터 이미지(SVG, Claude가 직접 그림). 원본 사진은 레포에 넣지 않음. 이유: 실제 얼굴 사진은 공개 후 회수가 어려움. 이미지 생성 도구가 없어 SVG로 그림 |
| 3 | 디자인 방향 | **결정 (10/15)**: 미니멀(흰 바탕, 여백) + 대시보드형(성과 수치를 큰 숫자 카드로). 포인트 딥그린, 본문 IBM Plex Sans KR, 수치·코드 JetBrains Mono. 이유: 이력서 강점이 실측 수치와 근거 있는 선택이라 수치가 읽히는 디자인 |
| 4 | 보너스: 언어 필터 / 타이핑 효과 / 폼 실제 전송 / 시스템 다크 모드 감지 | 미정 (a-8 전까지) |
| 5 | Projects 저장소 | **결정 (10/15)**: 결과물로 볼 수 있는 것만 이름으로 골라 표시. `library-search`(README·33커밋), `kafka-client`, `spring-redlock`. `skip-lock-inventory`는 뼈대(소스 1개)뿐이라 제외. 정렬은 최근 수정 순 |
| 6 | 기준값 | **결정 (10/15)**: 과제 기본값 그대로 (스크롤 탑 300px, 네비 변경 60px, threshold 0.2). README "기준값" 표에 명시 |
| 7 | GitHub Pages 켜기 (레포 Settings → Pages) | a-9에서 사용자가 직접 |
| 8 | 섹션 구성 | **결정 (10/15)**: Experience 섹션 추가(About 다음). 회사 2곳의 기간·역할과 대표 성과 몇 개만, 과하지 않게. 이유: 백엔드 경력이 핵심이라 별도 섹션이 읽기 쉬움 |
