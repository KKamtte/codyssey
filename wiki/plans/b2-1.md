## 결정 사항

| # | 항목 | 상태 |
|---|---|---|
| 1 | 저장 포맷 | **결정 (11/24, 사용자)**: JSONL. 이유: 한 줄 = 거래 하나라 한 줄씩 읽는 제너레이터 스트리밍과 잘 맞고, 숫자·태그 목록 같은 타입이 그대로 유지된다. CSV는 import/export에서만 쓴다 |
| 2 | update 방식 | **결정 (11/24, 사용자)**: 옵션 방식 `update --id <id> [--date] [--type] [--category] [--amount] [--memo] [--tags]`. 이유: 한 줄로 끝나 테스트·자동화가 쉽고 delete·search와 사용법이 같다. 바꿀 옵션이 하나도 없으면 오류 |
| 3 | 사용 중인 카테고리 삭제 | **결정 (11/24, 사용자)**: 기본은 막고 "사용 중인 거래 N건" + 힌트. `category remove <name> --replace-with <다른 카테고리>`를 주면 해당 거래를 옮긴 뒤(원자적 재작성) 삭제 |
| 4 | 보너스 범위 | **결정 (11/24, 사용자)**: 4개 모두(저장 원자성, 테이블 정렬, backup, 반복 내역) |
| 5 | 카테고리 파일이 비었을 때 | **결정 (11/24, 기본값)**: 원문 안 A. 처음 실행 때 기본 카테고리(food, transport, rent, salary, etc)를 만들고 안내 문구 출력. 이유: 처음 쓰는 사람이 `add`부터 막히지 않음. 사용자가 카테고리를 모두 지워도 다음 실행 때 다시 만든다(원문 "비어있으면" 그대로, 리뷰 6번 확인 후 유지. README에 적는다) |
| 6 | 거래 id | **결정 (11/24, 기본값)**: `TX-000001` 형식 일련번호. 새 id = 파일을 스트리밍하며 찾은 최대 번호 + 1. 중간 번호를 지우면 비지만 다시 쓰지 않고, **맨 마지막 번호를 지우면 그 번호는 다시 쓰인다**(a-5에서 발견해 문장 정정. 거래 id 를 다른 데이터가 참조하지 않아 문제없다고 보고 단순한 방식 유지) |
| 7 | 최신순 + 스트리밍 | **결정 (11/24, 기본값)**: 정렬 기준은 날짜 내림차순, 같은 날짜면 id 내림차순. `heapq.nlargest(limit, 제너레이터, key)`로 상위 N개만 메모리에 둔다(전체를 리스트로 올리지 않음). `list`·`search` 모두 `--limit`(기본 20) |
| 8 | 금액 | **결정 (11/24, 기본값)**: 양의 정수(원). CSV 스키마의 "양수 정수"와 맞춤 |
| 9 | Python 버전·실행 | **결정 (11/24, 기본값)**: 3.10 문법까지만 쓴다(로컬은 3.14). 실행은 과제 폴더에서 `python3 -m budget_app` |
| 10 | 데코레이터 | **결정 (11/24, 기본값)**: `@handle_errors`(앱 오류 → `[오류] 원인` + `[힌트]` + 종료 코드, 예상 못 한 오류도 스택트레이스 없이), `@log_execution`(명령 이름·결과·소요 시간을 `data/app.log`에 한 줄씩). 모든 명령 함수에 적용 |
| 11 | 종료 코드 | **결정 (11/24, 기본값)**: 0 정상, 1 입력·검증 오류와 없는 데이터, 2 사용법 오류(argparse 기본), 3 파일·저장 오류, 130 사용자 중단(Ctrl+C, 셸 관례. 리뷰 9번으로 표에 추가). 파일 내용이 잘못된 줄(필드 빠짐·형식 오류·UTF-8 아님)도 3, 몇 번째 줄인지 알려 줌 |
| 12 | 반복 내역 | **결정 (11/24, 기본값)**: 규칙을 `recurring.jsonl`(4번째 파일)에 저장. `recurring add`(대화형: 매월 며칠, 타입, 카테고리, 금액, 메모), `recurring apply --month YYYY-MM`로 그 달 거래 생성. 같은 규칙·같은 달은 두 번 만들지 않음(거래에 `recurring_id` 기록). 31일 규칙은 짧은 달의 마지막 날로 |
| 13 | 백업 | **결정 (11/24, 기본값)**: `backup`은 `data/backups/YYYYMMDD-HHMMSS/`에 데이터 파일을 복사하고 경로 출력 |
| 14 | 테스트 | **결정 (11/24, 기본값)**: 표준 `unittest`(임시 폴더를 `--data-dir`로). 실행 `python3 -m unittest` |
| 15 | 폴더·브랜치 | **결정 (11/24, 기본값)**: 과제 폴더 `01-ai-tools/B2-python-git/B2-1-budget-cli/`, 브랜치 `mission/b2-1-budget-cli`. `data/`는 `.gitignore` |
| 16 | add 날짜 빈 입력 | **결정 (11/24, 기본값, a-3에서 추가)**: 엔터만 치면 오늘 날짜. 이유: 가계부는 대부분 그날 쓰므로 입력을 줄인다. 프롬프트에 "엔터=오늘 YYYY-MM-DD"로 보여 준다 |
| 17 | 카테고리 이름 규칙 | **결정 (11/24, 기본값, 리뷰 12번)**: 한글·영문·숫자·`_`·`-`만, `-`로 시작 금지, 20자 이하. 이유: `\|`는 표 출력과, 앞의 `-`는 명령 옵션과, 공백·쉼표는 태그·CSV와 섞인다 |
