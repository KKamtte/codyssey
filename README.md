# codyssey

코디세이 2기 AI올인원 과정 과제 저장소.

## 구성

```
codyssey/
├── AGENTS.md          # AI 작업 규칙 (CLAUDE.md 는 이 파일을 불러온다)
├── 00-onboarding/     # 입학연수
├── 01-ai-tools/       # AI 도구 학습 (2026.05.07 ~ 2026.10.31)
├── 02-ai-advanced/    # AI 심화 학습 (2026.11.01 ~ 2027.03.31)
├── 03-ai-applied/     # AI 응용 학습 (2027.04.01 ~ 2027.09.30)
└── wiki/              # 학습 위키 (Karpathy LLM Wiki 패턴, 목차: wiki/index.md)
```

- 학습단계 → 분야(B1~B7) → 과제(B1-1 …) 순으로 둔다.
- 폴더명은 영문 kebab-case, 과제 코드는 코디세이 표기(`B1-1`) 그대로 쓴다.
- 과제 폴더는 과제를 시작할 때 만든다.
- 학습 중 정리한 내용, 계획, 문답 기록은 [wiki/](wiki/index.md)에 쌓는다.
